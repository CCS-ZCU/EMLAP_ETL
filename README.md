## Description

This repository contains
(1) code to produce a machine-readable and morphologically annotated version of the EMLAP data.
(2) computational readable version of the EMLAP corpus, avaialble in several formats with a different level of complexity.

To approach a more human-readable version of the corpus, please visit the GUI website: https://emlap.flu.cas.cz. There you can also find an additional documentation.

The repo takes as its input the manually curated OCR-layered PDF files and produces different versions of the output data critical for many downstreaming tasks.

The publicly avaialable versions of the data are collected in the directory `data/emlap_corpus_public/`, which we also make accessible directly from our server:
